# Consent for installs

Shared by groma-skills (catalog skills) and groma-lay-out (style tools). Every install command goes through these two rules.

## Asking first

Before running an installer: if one of its `touches` paths **already exists** in the project, ask the user once ("npx skills will update the existing skills-lock.json. Go ahead?"). Custom `install` commands always ask, they may install outside the project (graphify installs a user-level tool). On "no", write the command to `.groma/install.sh` instead.

## When commands cannot run

If the agent may not execute commands, or a command fails, write `<project>/.groma/install.sh`:

```sh
#!/bin/sh
# Generated by groma on <date>. Review, then run: sh .groma/install.sh
set -eu
<one command per line, in the order they were built>
```

Then tell the user to run `sh .groma/install.sh`. If the file exists from an earlier run, write `.groma/install-<YYYY-MM-DD>.sh`.
